2. Grundsatz: keine Datenerhebung

MatheSnack verarbeitet keine personenbezogenen Daten auf Servern des Anbieters. Es gibt keine Benutzerkonten, keine Registrierung, keine Eingabe von Namen, keine Analyse- oder Trackingdienste, keine Werbung und keine Weitergabe von Daten an Dritte. Alle Spiele entstehen auf dem Gerät aus einem kurzen Spielcode.

3. Einsatz im Unterricht

Lehrkräfte erzeugen auf ihrem Gerät einen QR-Code, Schülerinnen und Schüler scannen ihn und spielen auf ihrem eigenen Gerät. Dabei fließen keine Daten zwischen den Geräten und keine Daten an den Anbieter. Ergebnisse werden nicht eingesammelt; sie stehen nur auf dem jeweiligen Gerät. Die App fragt weder Namen noch Klassen ab.

4. Welche Daten auf dem Gerät gespeichert werden

Folgende Angaben werden ausschließlich im lokalen Speicher des Geräts abgelegt:

  • die zuletzt gewählten Einstellungen je Spiel (Thema, Dauer, Anzahl), damit sie beim nächsten Mal vorausgewählt sind
  • die eigene Bestleistung je Spiel und Thema
  • bei der Stationen-Rallye die bereits gesammelten Buchstaben
  • beim Bingo die eigene Karte, solange das Browserfenster bzw. die App geöffnet ist

Diese Daten werden nicht übertragen. Sie lassen sich auf der Startseite unter „Gespeicherte Daten löschen“ entfernen und werden beim Deinstallieren der App vollständig gelöscht.

5. Kamera

Zum Scannen eines QR-Codes kann MatheSnack auf Ihren Wunsch die Kamera verwenden. Ihr Gerät fragt dafür um Erlaubnis. Das Kamerabild wird ausschließlich auf dem Gerät ausgewertet, um den QR-Code zu erkennen; es wird weder gespeichert noch übertragen. Dasselbe gilt für ein Foto, das Sie über „Foto aufnehmen“ auswählen. Alternativ können Sie die Kamera-App Ihres Geräts verwenden oder den Code von Hand eingeben.

6. Spielcodes und QR-Codes

Ein Spielcode enthält nur das Spiel, das Thema, die Einstellungen und eine Zufallszahl, aus der die Aufgaben entstehen – keine personenbezogenen Daten. In einem QR-Code steht der Code hinter dem Zeichen „#“ einer Internetadresse. Dieser Teil wird beim Öffnen technisch nicht an den Webserver übertragen, sondern nur auf dem Gerät ausgewertet.
